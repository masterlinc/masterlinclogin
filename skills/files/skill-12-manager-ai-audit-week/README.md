# 管理者AI效率审计 Skill

> **一句话**：把你的工作记录丢给AI，30秒告诉你有多少时间花在了"假装管理"上。

## 这是什么

一个给你的 AI 助手（Claude / ChatGPT / DeepSeek 等）安装的"管理效率审计技能"。

安装后，AI 会变成一位拥有20年管理经验的"AI管理审计师"。你把一周的工作记录丢给它，它会：

1. 把你的每条工作记录分成三类：
   - ❶ **真正管理**（判断/协调/拍板）— 只有你能做的
   - ❷ **可以交但没交的** — 写个SOP就能交给别人
   - ❸ **纯重复劳动** — AI做更快更不出错
2. 算出你的"假装管理比例"
3. 找出最该先交给AI的3个任务
4. 给你3条具体的行动建议

## 为什么需要它

做了20年管理，我发现一个不好意思的事：

管理者70%的时间，花在了信息搬运、组装格式、重复确认上。这些事换成一个刚毕业有SOP的人也能做，甚至AI自己做更快。

但没人告诉你这件事。因为你的周报写得很全，会议参加得很多，消息回得很快——看起来很忙，看起来很负责。

**AI是一面镜子。它不夸你，也不骂你，它只是把你的工作拆开，一样一样摆在你面前，让你自己看。**

## 怎么用（30秒跑通）

### Step 1：安装 Skill

把以下内容完整复制，粘贴到你的 AI 助手对话框中，发送：

```
请阅读以下系统提示词，并在后续对话中严格按照它的角色、方法和输出格式执行。确认收到后回复"审计师已就位，请发送你的工作记录"。

---
{{粘贴 system-prompt.md 的完整内容}}
---

同时请阅读以下输出模板，审计报告必须严格按照此模板格式输出：

---
{{粘贴 audit-template.md 的完整内容}}
---
```

AI 会回复"审计师已就位"。

### Step 2：发送你的工作记录

把你的工作记录发给 AI。格式不限，可以是：

- 上周的周报
- 会议纪要
- 待办清单
- 随手写的工作备忘
- 微信聊天记录里提到的工作
- 甚至是一段口语化的"我这周大概做了这些事……"

越完整越好，但不需要格式化。AI 会自动解析。

### Step 3：获取审计报告

30秒内，AI 会输出一份完整的审计报告，包含：

- 核心数据（三分类占比 + 可释放时间）
- 一句话诊断
- 工作清单明细（分类 + 评分 + 理由）
- 优先自动化 TOP 3
- 3条行动建议

以下是一个管理者的真实审计结果（脱敏处理）：

---

"你的忙碌里，有很多是忙给自己看的。不是你的错，是惯性。28%的真正管理，意味着你有72%的时间，可以用来做更好的判断——如果愿意放手的话。"

**优先自动化 TOP 3**：
1. 周报数据汇总（每周3小时 → AI处理后15分钟）
2. 会议纪要整理（每周2.5小时 → AI处理后10分钟）
3. 跨部门进度跟进（每周2小时 → AI处理后20分钟）
