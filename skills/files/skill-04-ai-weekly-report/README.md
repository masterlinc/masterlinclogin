# AI 写周报法 Skill

> **一句话**：周报从 3 小时压到 20 分钟——素材随手记、AI 出初稿、人只改判断。每周 20 分钟，换来一篇每一句都是判断、不是流水账的周报。

## 这是什么

一个给你的 AI 助手（DeepSeek / Kimi / ChatGPT 等）安装的「AI 写周报」技能。

安装后，你把本周随手记的素材丢给它，它会生成四段周报初稿：

1. **① 本周完成** — 每条 30 字内，数字优先
2. **② 本周判断/决定** — 这周真正重要的决定
3. **③ 下周计划** — 可验证的动作 + 时间
4. **④ 需要老板知道的 1 件事** — 需要拍板 / 需要资源 / 需要知晓

## 为什么需要它

周日晚上，翻了一小时聊天记录，还是想不起这周干了什么。最后硬凑出一篇流水账，老板扫一眼就过，你自己也知道没写出价值。3 小时耗在「回忆」上，而不是「总结」上。

周报的难点从来不是「写」，是「记」。AI 再强，也写不出你没干过的事。这套方法的重心不在「怎么让 AI 写得好」，而在「怎么让素材记得住」。

## 怎么用（每周 20 分钟跑通）

### Step 1：素材随手记（周一到周五，每天 2 分钟）

每完成一件值得记的事，用一句话记下来：**做了什么 + 一个数字或结果**。

- 「周会上定了 Q3 预算口径」
- 「催了法务合同，已进审批流」
- 「处理了 12 条客服升级」
- 「渠道 A 转化率 1.2% → 1.8%」

唯一的要求：**别等周日回忆。** 周日回忆的成本是随手记的 30 倍——而且回忆出来的东西会自带美化。

补充一条纪律：**把「没干成的事」也记下来。** 比如「和 XX 的合同没谈拢，卡在条款」。周报里敢写没干成的事，比堆十件干成的事更显专业。

### Step 2：AI 初稿（周日 15 分钟）

把本周随手记 + 上周周报丢给 AI（安装好 Skill 后直接发素材即可）。生成后**先别改文字，先看结构**：哪些事没记、哪条事实错了——把缺的补上、错的划掉。

### Step 3：人只改判断（5 分钟）

只改三处，其他一律不动：

1. **结论**：本周真正重要的一件事，提到最前面；
2. **下周承诺**：下周要交付什么、什么时候交付；
3. **要老板知道的**：需要拍板 / 需要资源 / 需要知晓，只写一件。

改完即发。**不要陷入「把 AI 的句子改得更顺」**——那不是周报的价值。

## 三套变体怎么选

同一套素材，换一个目的，就是另一篇东西：

| 场合 | 用哪套 |
|---|---|
| 每周例行 | 普通周报（本 Skill 默认） |
| 季度/晋升/评审 | 述职周报（按 SKILL.md 变体 2 指令切换） |
| 专项汇报/要资源 | 汇报材料（按 SKILL.md 变体 3 指令切换） |

## 常见坑（对照自查）

1. **周日才开始回忆**：这是周报 3 小时的真正来源，解法只有素材随手记；
2. **让 AI 编**：素材没记全就直接发初稿。每周 30 秒扫一遍事实即可；
3. **下周计划写空话**：「持续推进」「加快进度」不是计划。计划 = 可验证的动作 + 时间；
4. **一篇周报打天下**：述职和日常周报要的是两种东西，用错变体等于把功劳簿写成流水账；
5. **不敢写没干成的事**：周报里「卡在条款」「方向待验证」写出来，比十件小事更能建立信任。
